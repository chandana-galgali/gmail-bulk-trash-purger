Then you're stuck deleting 50 at a time, page after page. This script does the deleting for you.

  • Fast: deletes 500 messages per API call.
  • Safe by design: only ever reads the Trash label, and has a dry-run mode.
  • One click: if your Trash is huge, it schedules itself to keep going until it's empty.
  • Optional autopilot: clear Trash daily so it never piles up again.

Why I built this

From my first year of college, my university email filled up with circulars, notices, newsletters and group mail. Like most students, I never cleaned it out.

Then, in my final year, we were told to bring our Google storage under a limit set by the college. That meant clearing out years of email. Moving it all to Trash was the easy part. Emptying Trash was not: every attempt at Delete forever ended in “An error occurred”, and deleting 100 at a time would have taken days.

So I wrote a script to do it for me. If you're a student facing a storage deadline, or anyone with a Trash that won't empty, I hope it saves you the same headache.

— Chandana

Set it up

  1. Create a project

    Open script.google.com and click New project.

  2. Paste the code

    Replace everything in Code.gs with the script below, then save.

  3. Turn on the Gmail API

    Click + next to Services in the sidebar, choose Gmail API, and click Add.

  4. Dry run

    Pick countTrash in the function menu and click Run. Approve the permissions (Google calls your own script “unverified”, so choose Advanced → Go to … → Allow). The log shows how much is in Trash, and nothing is deleted.

  5. Empty it

    Pick autoEmptyTrash and click Run. You can close the tab, and it carries on by itself until it's done.

Heads up: deletion is permanent. Anything in Trash when you run it is gone for good.

Keep it clean automatically

Run installDailyTrigger once and Trash is emptied every night. Run removeAllTriggers to stop. Want an undo window? Set EXTRA_QUERY: 'older_than:7d' at the top of the script.

Questions

Why does it need access to “all your email”?

Google only allows permanent deletion under the full Gmail scope; there's no narrower option. The script only lists and deletes messages labelled Trash, it runs as you, and it sends nothing anywhere. The whole thing is about 150 readable lines.

Doesn't Gmail empty Trash after 30 days anyway?

It does. Use this when you need the storage back now, or want Trash cleared on your own schedule.

How do I remove it later?

Run removeAllTriggers, delete the project, and optionally revoke access at Google Account → Third-party connections.

Does it work on a college or work (Google Workspace) account?

Yes, that's what it was built for. Some institutions block Apps Script or the Gmail API for student accounts. If you can't create a project or add the Gmail service, your administrator has turned it off.

It hit a quota error.

Gmail limits API use per day. Try again tomorrow; it picks up where it left off.
